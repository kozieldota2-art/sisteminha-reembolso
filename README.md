# Atreia — Aion 2 Global

Guia para as oito classes, progressão, sistemas e comparação de personagens.

## Netlify

Execute `npm run build:netlify`. O arquivo `netlify.toml` configura os assets e as funções públicas de consulta à NC. Builds e publicação são automáticos a partir de main.

As builds do guia são sugestões editoriais para teste. A análise local compara metas informadas pelo jogador; a opção IA prepara contexto para copiar, sem chamada a um modelo.

## Validação

Execute `node checks.cjs`.
